# 可选 QQ 群聊发送限频补丁

这是 QQ 接入层的源码补丁，**不会随记忆插件自动启用**，也不提供完整 QQ 接入程序。已安装的记忆、群友画像与关系功能不依赖它。

## 作用

- 每群共用发送额度：默认每 60 秒最多 6 次、每小时最多 40 次。按实际向 QQ 发起的发送尝试计数，失败的尝试也占额度。
- 文字气泡、语音、表情、合并转发和扩展接口发送共同计数；文件上传也计入。每次群文字回复最多拆成 2 个气泡。
- 达到上限时丢弃剩余回复，不排队补发。群聊断线时不保存待补发旧回复，避免重连后集中发送；私聊仍保留原有分段和离线队列。
- 被 @ 的消息仍保留原有触发优先级，但发送上限不被绕过。自然接话的原有 90 秒冷却保持不变。
- 额度保存在接入插件的 `mediaDir/group-send-limits.json`，重启后继续计数。此文件仅保存在使用者本机，不随补丁发布。
- 调试干跑拦截先于额度和真实发送，包括异步扩展接口及文件上传。

这些是本地减少刷屏的配置值，不代表腾讯公开的封禁阈值，也不能保证账号不会受到平台风控。

## 适用范围

基于 **DSH 0.2.1-rc.2** 和一份已扩展陪伴功能的 `dsh-onebot-qq 0.9.3` 构建。**同为 0.9.3 不代表内容相同**；普通上游安装或其他改版不能仅凭版本号套用。

`compatibility.json` 列出 7 个文件应用前后的 SHA-256。新增文件的应用前摘要为 `null`。应用前应核对所有基线摘要；不匹配时停止，按自己的接入层适配。补丁路径均相对于 QQ 插件目录，不包含本机安装路径。

## 手动应用

在没有运行 DSH 的情况下，进入匹配基线的 **QQ 接入插件目录**，先核对上述摘要，然后执行：

```powershell
# 替换为下载后补丁文件的绝对路径
git apply --check 'D:/downloads/group-send-limits.patch'
git apply 'D:/downloads/group-send-limits.patch'
```

检查失败就停止，不要强制应用。不具备该基线时，目录内补丁供开发者移植参考。

在 QQ 接入插件的配置项中可设置：

```yaml
groupSendRatePerMinute: 6
groupSendRatePerHour: 40
```

配置需要放在原 QQ 接入插件自己的 `config` 下。无效值回退到默认值，`0` 不会关闭限频。修改代码或配置后重启 DSH；不要放进记忆插件的配置中。

持久记录损坏时，群聊发送暂缓一小时；记录写入失败时拒绝群聊发送，私聊不受影响。该实现按一个活动桥接进程设计，不提供多进程共享额度的保证。

## 验证与许可

原补丁在实际 DSH 运行库中通过 20 项本地检查，覆盖并发、分钟/小时边界、重启、群间隔离、私聊、语音和干跑发送。检查不向真实 QQ 发消息；自动测试不能替代使用者自己的接入层验证。

发布整理另做补丁反向还原、基线摘要核对、正向应用和结果摘要核对，确保补丁可以完整重现已验证的 7 个文件。
